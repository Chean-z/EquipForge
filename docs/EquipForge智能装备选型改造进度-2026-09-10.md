## 数据字段复用约定

| 现有字段 | EquipForge 中的含义 |
| --- | --- |
| `product_id` | 设备编号 |
| `title` | 设备型号名称 |
| `brand` | 合成厂商名称 |
| `category` | 设备类别 |
| `description` | 应用场景与主要参数 |
| `highlights` | 分辨率、精度、接口、防护等级等结构化亮点 |
| `skus` | 配置或规格版本 |
| `price_major` | 合成参考采购价 |
| `stock` | 合成可用库存 |
| `source_platform` | 合成供应渠道 |
| `ships_to` | 可供货地区 |
| `material_tags` | 材料或设备属性标签（首版兼容旧结构） |

## 验收查询

1. `预算 5000 元，为流水线外观缺陷检测选择一款全局快门工业相机。`
2. `选择支持 Modbus TCP、至少 8 路数字量输入的边缘控制器。`
3. `比较适合机械臂定位的三款视觉设备，优先精度和响应速度。`
